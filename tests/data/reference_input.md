# Эталонное входное описание: калькулятор командной строки

Небольшой калькулятор командной строки для целых чисел.

## Функции

- Сложение, вычитание, умножение и целочисленное деление двух аргументов.
- Вызов одной командой: операция и два числа, результат печатается в stdout.
- Понятное сообщение об ошибке при делении на ноль и при нечисловом вводе.

## Ограничения

- Только стандартная библиотека Python, без сторонних зависимостей.
- Без сети, без файлов конфигурации, без интерактивного режима.

## Критерии успеха

- Каждая операция покрыта автотестом, тесты проходят.
- Ошибочный ввод даёт ненулевой код возврата и сообщение, а не трассировку.

## Масштабируемость

- Добавление новой операции — одна функция и один тест, без правки остального кода.
